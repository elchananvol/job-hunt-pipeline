# UI development

The React/Vite UI is part of [Job Pipeline](../README.md). Start the Python backend from the repository root, then run `npm ci` and `npm run dev` here. Open <http://localhost:5173>. Vite proxies `/api` and `/files` to the backend on port 8000.

For installation, Docker, and the complete workflow, use the [main README](../README.md).
